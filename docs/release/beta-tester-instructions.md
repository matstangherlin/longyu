# Longyu — instruções para testadores (RC2.2.3)

Use o Longyu por **20–40 minutos** como se tivesse acabado de encontrar o site.

## O que fazer

1. Comece **do zero** (conta nova ou perfil limpo).
2. Explore sem tutorial externo.
3. Se algo parecer confuso, mande **print** e diga **o que você esperava**.

## O que NÃO fazer

- Não peça lista de “clique aqui”.
- Não use ferramentas de debug / seed / skip.
- Não teste compra de Pro/Family como se estivessem à venda (Free Public Beta).
