# Beta support runbook (RC2.3.12)

Commercial mode: **FREE_ONLY**. No live charges.

## Categories

| Category | First response |
|---|---|
| Login / email not received | Resend; check spam; Auth redirects OA if social |
| Progress missing | Confirm account; refresh; claim flow |
| Audio | Retry; device silent switch; arbiter stuck → relaunch |
| Speech | Mic permission; technical failure must not punish |
| Hànzì | Clear/undo; rotate |
| Sync | Online flap; no double reward |
| Crash | Collect version + SHA + device; Sentry if configured |
| Billing TEST | Engineering only; beta users should not be charged |
| Delete account | Warn; complete deletion path |

## Ask for

app version · build SHA · device · Android version · route · description

## Never ask for

auth tokens · passwords · full purchase tokens · card numbers
