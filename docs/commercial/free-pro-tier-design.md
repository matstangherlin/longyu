# FREE / PRO tier design (RC2.3.11)

## FREE — must learn Mandarin for real

Included:

- Core Journey initial access (first pedagogical arc)
- Fundamental pronunciation / tones
- Basic Hànzì introduction
- Selected Culture items
- Daily practice (bounded)
- Limited Review

Value before paywall: audio, visual association, tone, Hànzì, conversational context.

Limit style: **advanced feature + depth**, not fake hearts or a dead demo.

Never paywall: bug retry, speech technical fallback, account sync, security, recovery.

## PRO — Longyu Pro

- Full Journey
- Unlimited practice
- Personal Mastery full recommendations
- Advanced speech practice
- Full Hànzì lab
- Culture deep content
- Advanced review + progress insights
- Offline/downloads only if actually shipped

Essential pedagogy is not exclusively locked such that FREE is useless.

## Paywall UX

One clean primary screen: what Pro unlocks, price, period, renewal, cancel, restore. No dark patterns, fake timers, or preselected expensive option without fair UX. Contextual paywall explains *why* a feature is Pro.
