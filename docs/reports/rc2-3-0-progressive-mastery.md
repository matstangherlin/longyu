# RC2.3.0 — Progressive Mastery Budgets

## Orçamento novo (`MASTERY_PASS_GRADED_BUDGET`)

| Pass | Nome | Min | Max | Objetivo cognitivo |
|---:|---|---:|---:|---|
| 1 | Descoberta / Reconhecimento | 7 | 9 | ensinar, reconhecer, ouvir, associar |
| 2 | Fixação / Discriminação | 8 | 11 | discriminar, reconstruir, comparar, recuperar |
| 3 | Uso / Produção | 10 | 13 | produzir, completar, responder, falar, conversar |
| 4 | Domínio / Transferência | 12 | 15 | transferir, contexto novo, independência |

**15 é teto.** Sem variedade cognitiva suficiente, o planner **não** preenche com repetição artificial.

## Foundation

`targetCount = authoredCount` permanece para foundation/sistema (sem padding inútil).  
Authored plans podem crescer só com conteúdo real (visual, contraste, produção, contexto).

## Labs

Tone/Pinyin/perception labs mantêm política própria (não forçar 12–15).

## Exemplos de perfil (5 tópicos piloto)

### 1. `p1-o-que-e-mandarim`
- P1: Descoberta 你好 + ouvir + situação humana (“pela manhã”) + camadas
- P2: match de camadas + discriminação fala×escrita
- P3: produção/contextual do cumprimento
- P4: transferência / conversa

### 2. `p1-o-que-e-pinyin`
- P1: Descoberta pinyin ligado ao som de 你好
- P2: discriminação som ↔ grafia
- P3: recuperação com menos apoio
- P4: uso em leitura/transferência leve

### 3. `p1-o-que-e-tom`
- P1: Descoberta mā/má/mǎ/mà + contraste
- P2: discriminação tonal
- P3: produção/identificação
- P4: transferência a palavras novas do mesmo contraste

### 4. `p1-o-que-e-hanzi`
- P1: Descoberta 你/好 forma+sentido
- P2: discriminação/reconstrução
- P3: montagem / recall
- P4: uso em contexto

### 5. `p1-primeiros-hanzi`
- P1: componentes com Descoberta
- P2–P4: progressão authored (sem padding cosmética)

## Critérios FAIL

- Pass 2 = Pass 1 maior → FAIL  
- Pass 3 majoritariamente multiple choice → FAIL  
- Pass 4 sem independência comunicativa quando aplicável → FAIL  
- Padding até 15 → FAIL
