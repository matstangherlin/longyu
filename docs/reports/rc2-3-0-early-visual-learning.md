# RC2.3.0 — Early Visual Learning (piloto)

## Regra

Conceito **concreto** introduzido → Descoberta/prática deve preferir apoio visual do banco `visualVocabulary.ts`.

Gate: `VISUAL_SUPPORT_MISSING` (somente quando visualizável e não abstrato).

## Piloto (não RC2.3.1 completa)

Mapa inicial: 水→water, 饭→rice, 茶→tea, 书→book, 车→car, 家→home, 猫→cat, 狗→dog, 手机→phone.

`enrichStepWithVisual` anexa `imageId`/`iconId` quando o banco tem o conceito.

## Abstratos (sem forçar imagem)

pinyin, tons, partículas, metalinguagem → áudio, contraste, tipografia, diagrama.

## First-session contract

Mistura perceptível: texto + som + visual + interação (quando o conteúdo permitir).

Expansão curricular completa → **RC2.3.1**.
