# RC2.3.7 — Owner UX Acceptance

`OWNER_UX_ACCEPTANCE` is never automatic. Physical Android device, current APK from this PR.

## Primeiro uso
- [ ] Guidance não exagera (no máx. 1 por sessão; 2 na primeira, a 2ª só depois da 1ª atividade).
- [ ] Jornada está clara.
- [ ] Primeira lição começa rapidamente.

## Respostas
- [ ] Feedback de acerto agradável (discreto).
- [ ] Feedback de erro útil ("Quase" + resposta + explicação).
- [ ] SFX não cansam (20 acertos seguidos).
- [ ] Haptics fazem sentido (uma vibração ao terminar a lição com um acerto).

## Áudio
- [ ] Modelo claro; nenhum som de interface por cima do mandarim.
- [ ] "Tocando…" só depois que o áudio começa de verdade.

## Fala
- [ ] Estados de gravação claros (Falar · Preparando… · Gravando… · Parar · Gravar novamente).
- [ ] Ouvir a própria gravação funciona; nenhum SFX entra na gravação.
- [ ] Fallback claro (continuar sem falar).

## Hànzì
- [ ] Canvas grande.
- [ ] Desfazer/limpar fáceis.
- [ ] Haptic não exagera.

## Cultura
- [ ] Reação clara.
- [ ] Retorno correto.

## Personal Mastery
- [ ] Seu Domínio parece simples (frase de primeiro uso uma vez).
- [ ] Não parece painel técnico (sem números).
- [ ] Praticar o que preciso faz sentido e volta a Seu Domínio.

## Conclusão
- [ ] Diz o que aprendi primeiro ("Você aprendeu").
- [ ] Mudança real de domínio aparece uma vez ("✓ … agora está firme.").
- [ ] Recompensa não domina.
- [ ] CTA claro.

## Navegação
- [ ] Retorno exato à Jornada (nó certo, nunca o topo).
- [ ] Voltar do Android em Seu Domínio leva à Revisão.

## Aparelho
- [ ] 360×640.
- [ ] 375×667.
- [ ] 390×844.
- [ ] Safe area Android (topo, barra de gestos, botão gravar, canvas).

## Pergunta central
"O app parece uma experiência única e terminada, ou ainda parece várias features coladas juntas?"
