### 4. Pinyin não é tradução  `NOTICE`

**Locução:** Esta é a confusão mais comum de quem começa. A tradução de 你好 é Olá. nǐ hǎo não traduz nada — mostra como soa. Pinyin é um mapa: leva você à pronúncia, mas não é o lugar.

**Em tela:** hànzì 你好 · pinyin nǐ hǎo · significado "Olá"
